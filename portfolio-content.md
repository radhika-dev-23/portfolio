# Portfolio Design Direction

## Overall Style

* Modern engineering / AI aesthetic
* Minimal and professional
* Dark theme
* Strong typography
* Subtle technical grid elements
* Restrained animations
* High readability
* Responsive design
* Mobile-first considerations

## Avoid

* Excessive gradients
* Neon hacker aesthetics
* Matrix-style animations
* Giant 3D objects
* Stock photographs
* Fake statistics
* Fake testimonials
* Skill percentage bars
* Excessive scrolling animations
* Generic motivational copy
* Invented achievements

## Design Principle

The portfolio should feel like a software engineer's personal engineering site rather than a generic student template.

The visual design should support the content rather than distract from it.
